# Labels de triagem

As skills falam em cinco papéis de triagem. Esta tabela liga cada papel à label usada nas issues deste repo.

| Papel nas skills  | Label no repo     | Significado                                       |
| ----------------- | ----------------- | ------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Falta o mantenedor avaliar a issue                |
| `needs-info`      | `needs-info`      | Espera mais informação de quem abriu              |
| `ready-for-agent` | `ready-for-agent` | Especificada por inteiro, um agente pode pegar    |
| `ready-for-human` | `ready-for-human` | Precisa de uma pessoa para implementar ou decidir |
| `wontfix`         | `wontfix`         | Não vai ser feita                                 |

Quando uma skill cita um papel, use a label da coluna do meio.

As labels de tipo (`bug`, `enhancement`, `question`, `documentation`) continuam valendo ao lado das de triagem.
